Simple Calculator

A calculator that adds, subtracts, multiplies, and divides.

Watch the demo

How I built it
  1. Design the HTML Structure: Create the outer container, an input field for the display screen, and a grid of buttons for digits (0-9) and basic operators (+, -, *, /).
  2. Style the Interface with CSS: Use CSS Grid or Flexbox to lay out the keypad neatly, customize button colors, and format the display screen for readability.
  3. Add Event Listeners in JavaScript: Attach click event handlers to each button to capture user input and display numbers or operators on the screen.
  4. Implement the Calculation Logic: Write JavaScript functions to process the mathematical expressions when the equals button (=) is clicked, and add functionality to clear (C) the display.

Technologies used

  • HTML5: Used to structure the calculator buttons and display screen.
  • CSS3: Used for styling the user interface, grid layout, and button hover effects.
  • JavaScript (ES6): Used to handle input logic, perform mathematical operations, and update the screen dynamically.

Library Management System

A console program for borrowing and returning books.

How I built it
  1. Design the Database Schema: Define tables or collections for Books, Users, and Transactions to keep track of available inventory, active loans, and due dates.
  2. Build Backend APIs: Develop CRUD (Create, Read, Update, Delete) routes to handle operations like adding new books, registering members, and recording checked-out items.
  3. Create the User Interface: Build responsive web pages featuring search and filter tools for books, borrow/return buttons, and user account dashboards.
  4. Implement Borrow & Return Logic: Write system rules to validate book availability, automatically update stock counts upon checkout, and compute late fees for overdue returns.

Technologies used

  • HTML5 & CSS3: Used to structure and style the user dashboard, search bars, and book inventory tables.
  • JavaScript (Node.js/Express): Used for backend routing, managing user sessions, and writing RESTful API endpoints.
  • Database (SQL/MongoDB): Used to store book records, user credentials, issue dates, and return deadlines.
